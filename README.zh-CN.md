# VCMI-FV 启动器 · 领域仓库

这里存放可被 VCMI-FV 启动器直接下载安装的「领域」（Realm）。
一个领域就是一套独立的 VCMI 模组组合，连同它自己的设置与存档空间，各个领域之间互不干扰。

## 如何使用

1. 打开 VCMI-FV 启动器（官方发行版已内置本仓库，无需额外设置）。
2. 切换到 `领域` 标签页，进入 `切换领域` 页面。
3. 点击 `远程领域`，浏览可下载的领域。
4. 找到喜欢的领域，点击 `下载`（过程中可随时 `取消`）。
5. 回到 `切换领域` 页面，选中刚安装的领域并进入，然后正常启动游戏。

列表支持按名称搜索、按标签筛选，并按 `有更新` / `未安装` / `已安装` 分组展示。

> 列表是空的？点开 `仓库源管理`，确认下面的「索引地址」在其中；没有就点 `添加` 粘贴进去。

## 常见问题

- **下载慢或失败**：领域包直接从 GitHub 下载，请确认能访问 `raw.githubusercontent.com`；已安装的领域离线也能正常游玩。
- **提示缺少外部模组**：该领域依赖你本机另行安装的模组，按提示到 `模组` 页或官方预设装好后再进入。
- **看不到新发布的领域**：列表有约 30 分钟的缓存，点 `刷新` 可立即重新拉取。
- **想回到原来的游戏环境**：在 `切换领域` 页面切回其他领域即可。
- **能改下载来的领域吗**：远程领域默认只读，避免更新时覆盖你的改动；有更新时可按提示选择更新或保留。

## 想分享自己的领域

用启动器的「导出领域」生成 `.vcmirealm` 包，然后在本仓库提 Pull Request 或联系维护者。
