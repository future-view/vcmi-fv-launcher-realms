# VCMI-FV-Launcher RealmsRepository

## How to use

1. Run `vcmi-fv-launcher` application.
2. Goto `Realm` tag page.
3. Goto `Switch Realm` page.
4. Click `Online Realms` button.
5. Click `Repository Sources Setting` button.
6. Input `JSON index file` URL, and click `Add` button.
7. Wait a moment. you can see more realm itmes.
8. Find what you like realm, click `download` button.
9. Return `Switch Realm` page, enter the realm you desire.

## JSON index file URL

URL: `https://raw.githubusercontent.com/future-view/vcmi-fv-launcher-realms/main/index.json`
